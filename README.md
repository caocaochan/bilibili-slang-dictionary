# Bilibili Slang Dictionary

A Chinese–English Yomitan dictionary of slang, memes, fandom terms, and other useful expressions found in Bilibili comments.

## Install

Download [`bilibili_slang.zip`](bilibili_slang.zip) and import it from Yomitan’s **Dictionaries** settings.

## Contents

- 18,868 dictionary terms with tone-marked readings and concise English definitions
- Simplified and traditional lookup forms
- Bilibili frequency ranking metadata
- Yomitan dictionary format 3

Candidates were selected from a Bilibili comment frequency corpus and filtered against large Chinese dictionaries. Example comments informed the definitions, but the comments themselves are not included in this release. Some obscure names and ambiguous expressions were skipped; a few pinyin or gloss choices may still need correction.
