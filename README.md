# Bilibili Slang Dictionaries

Chinese–English slang, memes, fandom and gaming terms, historical and fantasy vocabulary, and useful expressions from web novels and danmei, with sources in the BilibiliFreq project ledger.

## Yomitan

Download [`bilibili_slang.zip`](bilibili_slang.zip) and import it from Yomitan's **Dictionaries** settings.

For automatic updates, add this stable dictionary index URL in Yomitan:
`https://raw.githubusercontent.com/caocaochan/bilibili-slang-dictionary/main/index.json`
The index points to the ZIP attached to the latest GitHub release, so the URL
does not change between releases.

## MDict-compatible apps

Download [`bilibili_slang.mdx`](bilibili_slang.mdx) and add it to an MDict-compatible dictionary app.

## Contents

- 26,543 dictionary terms with pinyin and concise English definitions
- Simplified and traditional lookup forms
- No frequency rankings; source credits and reuse notes are provided separately
- MDict package: MDX 2.0, 43,926 Simplified and Traditional headwords
- Yomitan package: dictionary format 3

The original candidates were selected from a Bilibili comment corpus and filtered against large Chinese dictionaries. This snapshot adds 7,338 entries translated from supplied Chinese glosses, retains 55 supplied English definitions, and includes other independently sourced definitions where the evidence supports a useful sense. Candidates without a verified sense remain in the project review queue and are not included in this build. The Yomitan ZIP contains per-entry source credits and reuse notes; the project does not claim a single redistribution license for all source material.

## Files
